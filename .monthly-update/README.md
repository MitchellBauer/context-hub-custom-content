# Documentation maintenance records

All Context Hub custom-pack maintenance work belongs in this workspace.
Use a dated folder under `.monthly-update/` for scripts, downloaded sources,
staging files, backups, and verification records.

- `2026-10-04/`: historical October update records, relocated from the old
  Context application's `.byod-update/` folder on November 1, 2026.
- `2026-11-01/`: November update backups and verification results.

Finished documentation lives in the pack directories, with installed copies
in each pack's `dist/`. These maintenance folders are archives, not additional
Context Hub sources.
